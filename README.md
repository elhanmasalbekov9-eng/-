# Крестики-нолики на Java

Консольная игра «Крестики-нолики» для двух игроков. Учебный проект по Java.

## Правила игры

- Поле 3×3, играют два игрока: **Игрок 1 (X)** и **Игрок 2 (O)**.
- Игроки ходят по очереди, вводя номер клетки от 1 до 9:

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

- Кто ходит первым, выбирается случайно.
- Побеждает тот, кто первым поставит три своих символа в ряд: по горизонтали, по вертикали или по диагонали.
- Если все клетки заняты и никто не победил, объявляется ничья.

## Как запустить

Нужен установленный JDK (Java Development Kit).

```
javac Main.java
java Main
```

## Пример игры

```
=== КРЕСТИКИ-НОЛИКИ ===
Вводите номер клетки от 1 до 9:
Первым ходит: Игрок 2 (O)

   |   |
---+---+---
   |   |
---+---+---
   |   |

Игрок 2 (O), ваш ход (1-9): 5
```

## Как работает код

Вся программа находится в файле `Main.java`.

### Константы и массивы

| Имя | Тип | Назначение |
|-----|-----|-----------|
| `SIZE` | `int` | размер поля (3) |
| `EMPTY` | `char` | символ пустой клетки |
| `SYMBOLS` | `char[]` | символы игроков: `X` и `O` |
| `NAMES` | `String[]` | имена игроков |

Игровое поле хранится в двумерном массиве `char[][] board`.

### Методы

| Метод | Что делает |
|-------|-----------|
| `main` | выводит приветствие и запускает игру |
| `playGame` | главный игровой цикл (`while`): ходы, проверка победы и ничьей |
| `createBoard` | создаёт пустое поле и заполняет его пробелами |
| `printBoard` | выводит поле на экран |
| `askMove` | запрашивает ход и проверяет ввод, пока он не будет верным |
| `getRow`, `getCol` | переводят номер клетки (1–9) в строку и столбец массива |
| `checkWin` | проверяет строки, столбцы и обе диагонали |
| `getResultText` | возвращает текст итога игры (через `switch`) |

### Ход игры

1. `playGame` создаёт поле и случайно выбирает, кто ходит первым.
2. В цикле `while` на экран выводится поле и вызывается `askMove`.
3. Выбранная клетка заполняется символом текущего игрока.
4. `checkWin` проверяет победу. Если победы нет и поле заполнено, объявляется ничья. Иначе ход переходит к другому игроку.
5. В конце игры выводятся результат и статистика: число ходов и процент заполнения поля.

### Защита от неверного ввода

Программа не падает, если игрок ввёл не то, что нужно. Метод `askMove` повторяет запрос, если:

- введён текст вместо числа (проверка через `scanner.hasNextInt()`);
- число не входит в диапазон от 1 до 9;
- выбранная клетка уже занята.
